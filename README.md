# 🧩 Aprendendo COBOL

> **Um passo de cada vez, um `DISPLAY` de cada vez.**
> Porque aparentemente, aprender uma linguagem criada para sistemas corporativos também pode ser divertido. 😄

Este repositório nasceu como meu espaço de **estudo e prática de COBOL**.

Aqui registro minhas aulas, exercícios, testes de código, descobertas e, principalmente, os erros que fazem parte do processo de aprender programação.

A ideia não é apenas guardar códigos, mas acompanhar minha **evolução ao longo do aprendizado**.

---

## 🎯 Objetivo

Estou estudando COBOL para entender melhor uma linguagem que possui uma longa história na computação e que continua presente em sistemas corporativos de grande importância.

Durante o aprendizado, pretendo praticar conceitos como:

* Estrutura de programas COBOL
* Variáveis e tipos de dados
* `DISPLAY` e `ACCEPT`
* Condicionais
* Estruturas de repetição
* Manipulação de strings
* Tabelas e estruturas de dados
* Arquivos e registros
* Processamento de dados
* Organização e boas práticas de código

---
